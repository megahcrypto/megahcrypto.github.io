1. Penerimaan Syarat & Ketentuan

Dengan mengakses dan menggunakan platform Megah Crypto (selanjutnya disebut "Platform"), Anda menyatakan telah membaca, memahami, dan menyetujui untuk terikat dengan Syarat & Ketentuan ini. Jika Anda tidak setuju dengan salah satu bagian dari Syarat & Ketentuan ini, harap segera hentikan penggunaan Platform.

Platform ini menyediakan layanan pembuatan token kripto tanpa coding (no-code token generator) yang dapat diakses oleh pengguna di seluruh dunia.

⚠️ Penting: Syarat & Ketentuan ini berlaku untuk semua pengguna Platform, termasuk tanpa batasan pengguna yang menggunakan fitur pembuatan token, panduan, atau layanan lainnya.

2. Deskripsi Layanan

Megah Crypto adalah platform yang memungkinkan pengguna untuk membuat token kripto sendiri (ERC20 dan BEP20) tanpa memerlukan keahlian pemrograman. Layanan yang kami sediakan meliputi:

  • Generator Token - Alat untuk membuat token kripto kustom di berbagai blockchain (BNB Chain, Core Chain, Riche Chain, dan lainnya)
  • Panduan & Tutorial - Materi edukasi tentang cara membuat token kripto dan memahami teknologi blockchain
  • Kode Sumber - Penyediaan kode sumber Solidity dari token yang telah dibuat untuk keperluan verifikasi dan audit
  • Integrasi Wallet - Koneksi dengan wallet Web3 seperti MetaMask dan Trust Wallet
  • Jasa Pembuatan Token - Layanan profesional pembuatan token kripto dengan smart contract OpenZeppelin dan fitur custom sesuai kebutuhan

💡 Catatan: Platform berfungsi sebagai alat bantu untuk membuat token kripto. Megah Crypto tidak bertanggung jawab atas penggunaan token yang dibuat oleh pengguna, termasuk namun tidak terbatas pada aktivitas ilegal, penipuan, atau pelanggaran hukum lainnya.

2.1 Layanan Jasa Pembuatan Token Kripto

Selain platform generator token mandiri, Megah Crypto juga menyediakan layanan jasa pembuatan token kripto profesional bagi Anda yang menginginkan solusi lebih personal dan siap pakai. Layanan ini dirancang untuk proyek dengan kebutuhan spesifik atau bagi Anda yang tidak memiliki waktu untuk mempelajari proses pembuatan token sendiri.

A Ruang Lingkup Layanan

  • Pembuatan Token Standar - Token kripto dengan smart contract berbasis OpenZeppelin yang aman dan teraudit. Cocok untuk proyek komunitas, utility token, atau fundraising.
  • Custom Smart Contract - Pengembangan kontrak pintar dengan fitur sesuai kebutuhan spesifik proyek Anda.
  • Multi-Blockchain Deployment - Deploy token di berbagai jaringan blockchain seperti BNB Chain, Ethereum, Core Chain, Riche Chain, Polygon, dan Tron.
  • Native Coin & Blockchain - Layanan konsultasi dan pengembangan untuk proyek skala besar seperti native coin atau blockchain sendiri.

B Harga & Paket Layanan

Kami menawarkan beberapa paket layanan dengan harga yang transparan dan kompetitif:

  • Paket Basic - Mulai Rp300.000 (Token standar OpenZeppelin, deploy 1 blockchain, termasuk source code dan verifikasi kontrak)
  • Paket Standard - Mulai Rp500.000 (Token + 2 fitur custom seperti tax/burn, deploy 2 blockchain, source code + verifikasi)
  • Paket Premium - Mulai Rp800.000 (Custom contract lengkap, multi-chain deploy, fitur custom unlimited, source code + verifikasi)
  • Paket Enterprise - Custom (Native coin/blockchain, full custom development, dedicated team, audit & security)

Harga belum termasuk biaya gas jaringan yang berlaku.

C Fitur Custom yang Tersedia

Kami dapat menambahkan berbagai fitur canggih ke dalam smart contract token Anda, antara lain:

Buy Tax (Pajak Pembelian)
Sell Tax (Pajak Penjualan)
Mint Function (Cetak Token)
Burn Function (Bakar Token)
Blacklist (Blokir Alamat)
Whitelist (Izin Khusus)
Anti-Whale (Batas Maksimal)
Timelock (Lock Contract)
Multi-Sig Wallet
Auto LP (Liquidity)
Reflection (Refleksi)
Anti-Bot Protection

D Proses Pengerjaan

  1. Konsultasi - Diskusikan kebutuhan dan spesifikasi token Anda dengan tim kami
  2. Pembuatan - Tim kami mengembangkan smart contract sesuai spesifikasi
  3. Review - Anda memeriksa dan menyetujui hasil pekerjaan
  4. Deploy - Kami melakukan deployment token ke blockchain yang dipilih
  5. Serah Terima - Anda menerima source code, alamat kontrak, dan dokumentasi lengkap

Estimasi Waktu: Token standar 1-2 jam, custom contract 2-8 jam, native coin/blockchain 1-4 minggu.

E Jaminan Keamanan

Semua token yang kami buat menggunakan smart contract berbasis OpenZeppelin, library smart contract paling aman dan terpercaya di ekosistem blockchain. OpenZeppelin telah melalui audit keamanan dan digunakan oleh proyek-proyek besar di dunia.

✅ Garansi Keamanan: Kami memastikan setiap token yang dibuat bebas dari kerentanan umum dan telah melalui proses verifikasi sebelum deploy. Source code diberikan lengkap untuk transparansi penuh.

F Syarat & Ketentuan Layanan Jasa

  • Pembayaran - Pembayaran dilakukan sesuai kesepakatan, biasanya 50% di awal dan 50% setelah deploy selesai.
  • Revisi - Revisi kecil (perubahan nama, simbol, supply) tidak dikenakan biaya tambahan. Revisi besar (perubahan arsitektur kontrak) akan dikenakan biaya tambahan sesuai kesepakatan.
  • Waktu Pengerjaan - Estimasi waktu diberikan berdasarkan kompleksitas proyek dan dapat berubah sesuai kebutuhan.
  • Biaya Gas - Biaya gas jaringan menjadi tanggung jawab klien dan tidak termasuk dalam biaya jasa.
  • Source Code - Source code token menjadi milik klien setelah pembayaran lunas dan dapat digunakan sesuai kebutuhan.
  • Dukungan Pasca-Deploy - Kami memberikan dukungan teknis selama 7 hari setelah deployment untuk memastikan token berjalan dengan baik.

⚠️ Catatan: Layanan jasa pembuatan token adalah layanan tambahan di luar platform generator mandiri. Syarat dan ketentuan ini berlaku khusus untuk layanan jasa dan merupakan bagian dari Syarat & Ketentuan Megah Crypto secara keseluruhan.

3. Kewajiban Pengguna

Sebagai pengguna Platform, Anda setuju untuk:

  • Menggunakan Platform dengan Bijak - Menggunakan Platform hanya untuk tujuan yang sah dan tidak melanggar hukum yang berlaku
  • Menjaga Keamanan Wallet - Bertanggung jawab penuh atas keamanan wallet Web3 Anda dan tidak membagikan kunci privat kepada siapa pun
  • Memverifikasi Informasi - Memeriksa kembali semua informasi yang Anda masukkan sebelum melakukan deployment token
  • Mematuhi Hukum - Mematuhi semua hukum dan peraturan yang berlaku di yurisdiksi Anda terkait dengan penggunaan token kripto
  • Tidak Menyalahgunakan Platform - Tidak menggunakan Platform untuk kegiatan ilegal, penipuan, atau merugikan pihak lain

⚠️ Larangan: Pengguna dilarang menggunakan Platform untuk membuat token yang bertujuan untuk:

  • Penipuan atau skema Ponzi
  • Pencucian uang atau aktivitas ilegal lainnya
  • Melanggar hak kekayaan intelektual orang lain
  • Menyebarkan konten yang bersifat ofensif atau berbahaya

4. Biaya & Pembayaran

Penggunaan Platform Megah Crypto untuk membuat token kripto bersifat gratis. Namun, pengguna tetap bertanggung jawab atas:

  • Biaya Gas Jaringan - Biaya transaksi yang dibebankan oleh blockchain yang dipilih (BNB Chain, Core Chain, Riche Chain, dll.)
  • Biaya Jaringan Tambahan - Biaya apa pun yang mungkin dikenakan oleh pihak ketiga atau wallet yang digunakan

Untuk layanan jasa pembuatan token kripto, biaya jasa terpisah dari biaya gas jaringan dan diatur sesuai kesepakatan antara klien dan Megah Crypto.

💡 Transparansi: Megah Crypto tidak memungut biaya tambahan di luar biaya gas jaringan untuk platform generator mandiri. Untuk layanan jasa, semua biaya disepakati di awal dan tidak ada biaya tersembunyi.

5. Kekayaan Intelektual

Semua konten yang tersedia di Platform, termasuk namun tidak terbatas pada teks, grafik, logo, ikon, gambar, audio, video, dan perangkat lunak, adalah milik Megah Crypto atau pemberi lisensinya dan dilindungi oleh hukum hak cipta dan kekayaan intelektual lainnya.

  • Kode Sumber Token - Kode sumber token yang dihasilkan oleh Platform dapat digunakan, dimodifikasi, dan didistribusikan oleh pengguna sesuai dengan lisensi MIT yang berlaku
  • Konten Platform - Materi edukasi, panduan, dan konten lainnya di Platform tidak boleh disalin, dimodifikasi, atau didistribusikan tanpa izin tertulis dari Megah Crypto
  • Merek Dagang - Nama "Megah Crypto" dan logo terkait adalah merek dagang terdaftar dan tidak boleh digunakan tanpa izin
  • Kode Sumber Jasa - Untuk layanan jasa pembuatan token, source code menjadi milik klien setelah pembayaran lunas, namun Megah Crypto berhak menggunakan pengetahuan dan pengalaman dari pengerjaan untuk pengembangan layanan.

6. Batasan Tanggung Jawab

Dengan menggunakan Platform, Anda memahami dan menyetujui bahwa:

  • Penggunaan Risiko Sendiri - Platform disediakan "sebagaimana adanya" tanpa jaminan apapun, baik tersurat maupun tersirat
  • Tanggung Jawab Pengguna - Anda sepenuhnya bertanggung jawab atas token yang Anda buat dan konsekuensi dari penggunaannya
  • Keterbatasan Tanggung Jawab - Megah Crypto tidak bertanggung jawab atas kerugian langsung, tidak langsung, insidental, khusus, atau konsekuensial yang timbul dari penggunaan Platform
  • Kegagalan Jaringan - Megah Crypto tidak bertanggung jawab atas kegagalan jaringan blockchain, keterlambatan transaksi, atau masalah teknis lainnya di luar kendali kami
  • Layanan Jasa - Untuk layanan jasa pembuatan token, tanggung jawab Megah Crypto terbatas pada pengerjaan sesuai spesifikasi yang disepakati. Kami tidak bertanggung jawab atas kinerja token di pasar atau penggunaan oleh pihak ketiga.

⚠️ Catatan: Megah Crypto tidak bertanggung jawab atas kehilangan aset akibat kesalahan pengguna, seperti memasukkan alamat wallet yang salah atau kehilangan kunci privat.

7. Privasi & Keamanan Data

Megah Crypto menghargai privasi Anda. Kebijakan privasi kami menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda:

  • Data yang Dikumpulkan - Kami hanya mengumpulkan data yang diperlukan untuk pengoperasian Platform, seperti alamat wallet dan preferensi pengguna. Untuk layanan jasa, kami mengumpulkan data kontak dan spesifikasi proyek.
  • Penggunaan Data - Data digunakan untuk meningkatkan layanan dan memberikan pengalaman pengguna yang lebih baik
  • Keamanan Data - Kami menerapkan langkah-langkah keamanan yang sesuai untuk melindungi data dari akses tidak sah
  • Cookie - Platform menggunakan cookie untuk meningkatkan fungsionalitas dan pengalaman pengguna
  • Pihak Ketiga - Kami tidak menjual atau membagikan data pribadi kepada pihak ketiga tanpa persetujuan Anda

🔒 Keamanan: Alamat wallet dan informasi transaksi Anda hanya diproses melalui blockchain dan tidak disimpan secara permanen di server kami. Data kontak untuk layanan jasa disimpan secara aman dan hanya digunakan untuk keperluan komunikasi proyek.
